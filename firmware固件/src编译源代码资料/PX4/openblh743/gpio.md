# OpenblH743VIT6 — PX4 Firmware

STM32H743VIT6 flight controller, Board ID = 18848.

## Pin Definitions

### SPI

| Bus | Function | SCK | MISO | MOSI | CS |
|------|------|-----|------|------|----|
| SPI1 | OSD (AT7456E) | PA5 | PA6 | PA7 | PC4 |
| SPI2 | IMU0 (MPU6500) | PB13 | PB14 | PB15 | PB12 |
| SPI3 | IMU1 (MPU6500) | PB3 | PB4 | PD6 | PD7 |

### I2C

| Bus | SCL | SDA | Function |
|------|-----|-----|------|
| I2C1 | PB6 | PB7 | Barometer (BMP280/SPL06) |
| I2C2 | PB10 | PB11 | Compass (IST8310) |

### UART

| Function | Hardware | TX | RX |
|------|------|----|----|
| USB | OTG1 | PA11 (DM) | PA12 (DP) |
| GPS1 | USART1 | PA9 | PA10 |
| TEL1 | USART2 | PA2 | PA3 |
| GPS2 | USART3 | PD8 | PD9 |
| TEL2 | UART4 | PA0 | PA1 |
| RCIN | USART6 | PC6 | PC7 |
| URT6 | UART7 | PE8 | PE7 |
| TEL3 | UART8 | PE1 | PE0 |

> UART7 is physically the ESC telemetry port (PE8/PE7); in PX4 it is exposed as generic serial port URT6 (`/dev/ttyS6`). For ESC telemetry: `tap_esc start -d /dev/ttyS6`.

### PWM

| Channel | Timer | Pin |
|------|--------|------|
| 1-4 | TIM1 CH1-4 | PE9, PE11, PE13, PE14 |
| 5-8 | TIM4 CH1-4 | PD12, PD13, PD14, PD15 |
| 9-10 | TIM15 CH1-2 | PE5, PE6 |
| 11 | TIM3 CH4 | PB1 |
| 12 | TIM3 CH3 | PB0 |

### Others

| Function | Pin |
|------|------|
| SD card | SDMMC1: PC12(CK), PD2(CMD), PC8-11(D0-D3) |
| Safety switch | PB2 |
| RGB LED | PE2(R), PE3(G), PE4(B) |
| CAN | PB8(RX), PB9(TX) |
| SWD | PA13, PA14 |
| ADC voltage | PC0 (ADC1_IN10) |
| ADC current | PC1 (ADC1_IN11) |

## Flash Layout

| Region | Address | Size |
|------|------|------|
| Bootloader | 0x08000000 | 128 KB |
| Firmware | 0x08020000 | 1920 KB |

## Build

Toolchain must be **GCC 10.2.1** (H7 code generated by GCC 13.x will not boot).

Two variants (flash is only 1920KB, CAN and DDS are mutually exclusive):

| Variant | Command | Description |
|------|------|------|
| Main board (with CAN) | `make openbl_h743_default` | UAVCAN enabled, UXRCE_DDS disabled |
| DDS variant | `make openbl_h743_dds` | UXRCE_DDS enabled, UAVCAN disabled |

```bash
cd PX4-Autopilot
make openbl_h743_default   # or make openbl_h743_dds
```

Output `build/openbl_h743_<label>/openbl_h743_<label>.px4`. Board ID 18848, APM bootloader compatible.

For the full build/flash flow (including merged bootloader + firmware hex), see [Build & Flash Guide](readme.md).

## Sensor Status

Currently all online: IMU0 (SPI2), IMU1 (SPI3), SPL06 barometer (I2C1 0x77), QMC5883P compass (I2C1 0x2C), battery ADC, AT7456E OSD (SPI1, CS PC4), CAN (UAVCAN, PB8/PB9).

> Note: SPI2 (IMU0) has a DMA conflict; DMA is currently temporarily disabled in favor of polling mode. PWM mapping and CAN configuration are detailed in the Build & Flash Guide.
