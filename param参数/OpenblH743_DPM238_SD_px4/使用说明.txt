OpenblH743VIT6 + DPM238 (INA238 数字功率计) —— SD 卡配置使用说明
================================================================

结论: 当前 openbl_h743_default 固件【已内置 INA238 驱动】(default.px4board 第 28-32 行
早已启用 CONFIG_DRIVERS_POWER_MONITOR_INA220/226/228/238 + VOXLPM, 已链接进 .bin)。
所以接入 DPM238【不需要重编译、不需要阉割任何功能、不增加 flash】, 只需下面 SD 卡配置。

本文件夹结构(把 etc 整个拷到 SD 卡根目录):
    etc/config.txt    (可选, 见第 3 节)
    etc/extras.txt    (真正激活 INA238 的脚本)


[1] 接线
    DPM238 的 I2C 接到飞控的 I2C 引脚, 本板两条 I2C 都可用:
        bus1 = I2C1 (PB6/PB7)      —— 板载气压计/罗盘在同一条上
        bus2 = I2C2 (PB10/PB11)
    本套配置按实测接线设为 bus1 (-b 1): i2cdetect -b 1 扫到 0x40 即 DPM238。
    若不确定接到哪条: 开机后 QGC → 分析工具 → MAVLink 控制台(提示符 pxh>), 分别执行
        i2cdetect -b 1
        i2cdetect -b 2
    哪个扫描结果出现 0x40 器件, 就把 etc/extras.txt 里的 -b 改成几。

[2] 放卡上电
    把整个 etc 文件夹复制到 SD 卡根目录(卡上应有 /etc/extras.txt 与 /etc/config.txt),
    插卡上电。飞控启动末尾会自动执行 extras.txt, 运行:
        ina238 start -X -b 1 -a 0x40 -k
    (-k: 若开机时电池还没接/器件晚就绪, 驱动会周期重试直到 DPM238 就绪; 不需要可去掉 -k。
    注意: 此固件里 -f 是 I2C 总线频率参数(需带 kHz 数值), 不是重试开关, 别用它。)

[3] config.txt 的作用
    extras 之前 rcS 也会读 etc/config.txt, 里面两条参数(SENS_EN_INA226=0/INA238=1)
    在本板此固件中没有任何启动逻辑读取(纯惰性参数), 所以放不放都不影响 DPM238。
    保留仅为与官方配置包保持一致; 想删可直接删。

[4] QGC 检查
    - HUD/电源栏应显示 DPM238 的电压与电流; 电流不再由模拟通道(PC0/PC1)提供。
    - MAVLink 控制台确认驱动在跑:
          ina238 status
          listener battery_status     # 看 voltage_v / current_a / connected = true
    - 若日志报 “Failed to init INA238 on bus N” → 多为总线号或接线错, 回第[1]步重测。

[5] 电源参数 (QGC 参数 → 搜关键字)
    数字功率计默认挂在 BAT1, 与当前模拟电池同一组参数, 所以原有
        BAT1_N_CELLS / BAT1_CAPACITY / BAT1_V_CHARGED / BAT1_V_EMPTY
    直接沿用, 一般不用改。
    确认驱动默认值即可(与 DPM238 匹配):
        INA238_CURRENT = 327.68
        INA238_SHUNT   = 0.0005

[6] 与模拟 ADC 电源计(board_adc)的关系 —— 重点
    rc.board_sensors 每次开机都会先启动 board_adc(模拟 ADC 电池源)。
    INA238 与它都属于 “Power Module” 电源, 默认共用 BAT1 通道,
    若两者同时在发, QGC 电量可能出现互相覆盖/异常(跳变或归零)。处理:
      a) 临时:  MAVLink 控制台执行 board_adc stop(重启后恢复)
      b) 永久:  打开 etc/extras.txt, 把最后一行取消注释, 每次开机自动停掉:
                    board_adc stop
    若想彻底从固件去掉模拟电池源(不用每次靠 extras), 则需“固化进固件”路线
    (改 rc.board_sensors 重新编译) —— 需要时说一声即可。

[7] 撤销
    删掉 SD 卡上的 etc 文件夹即可完全恢复原状, 不影响固件。
