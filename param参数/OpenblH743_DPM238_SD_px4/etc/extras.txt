# ============================================================
#  OpenblH743VIT6 + DPM238 (INA238 数字功率计)
#  放到 SD 卡 /etc/ 目录 (SD:/etc/extras.txt), 开机自动执行
# ============================================================
# I2C 总线对应(本板):  bus1 = I2C1 (PB6/PB7)   ← 气压计/罗盘在这条
#                      bus2 = I2C2 (PB10/PB11)
# 若不确定 DPM238 接的是哪条: QGC MAVLink 控制台(pxh>)执行
#     i2cdetect -b 1   或    i2cdetect -b 2
# 哪条扫到 0x40 就把下面 -b 改成几。
ina238 start -X -b 1 -a 0x40 -k
#    -X      外置 I2C 总线
#    -b 1    I2C 总线号(1 或 2)
#    -a 0x40 INA238 器件地址(DPM238 默认 0x40)
#    -k      探测失败时周期性重试(适合电池后接/上电晚于飞控); 不需要可去掉

# 板载模拟 ADC 电源计(board_adc, PC0/PC1)与 DPM238 二选一。
# 若 QGC 电量读数仍来自模拟通道/两源互相覆盖, 取消下行注释重试(每次开机都会执行):
board_adc stop
